## Requests (for the integrator, Lane P / C / D)

- Request: `--fight colambros` uses `arena.spawns.monster` and the pond; the caldera (Lane C/D) should mark heat vents as kind `"vent"` and lava as `"lava"` (unwalkable) so the trail rule (H323) and `allowed_kinds` (H327) bite. Nothing in the brain needs the kinds to exist.
- Request: the view should glow the `quill` role (emission) when `monster_state` carries `smoulder: true` ("glowing quill tips mean the trails are live") and show the `charge` telegraph as one lane (the brain issues it as per-hex segments named `charge`, plus `charge_vent` and `quill_scatter` harmless ones; `name` is in the payload and the event).
- Request: `sim.hurt` truncates a monster's path on stagger; the brain re-asserts the charge line each tick (H323), but a committed charge would be cleaner with a `u.committed` flag the sim honours in `_stop`. Not needed for Phase 2.
- Request: the fight's `monster_anim` handler already reads `speed`; `charge` is a loop clip started when the run begins (after `dirt_scrape`), so no change needed there.
- Request: the manifest's `quills`, `stance`, `arms` keys are new row fields (additive); `HHMonsterBody` ignores them.
