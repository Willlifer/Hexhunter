## Requests to the integrator (Lane P)

- **R1** `src/kit/gk_materials.gd`: merge `HHPondGen.ROLES` into `GKMaterials.ROLES` (eight entries, same shape; `water_shallow` carries `alpha` so it takes the clear shader). `HHPondGen.role()` switches to them automatically; nothing else changes.
- **R2** `src/core/arena.gd`: carry an optional `cover: bool` through `to_dict` / `from_dict` (`c.get("cover", false)`, written only when true). Until then `arenas/pond.json` has a top-level `cover` list and `HHPondGen.cover_hexes(a)` rebuilds the flags.
- **R3** `src/game/boot.gd`: a `--bench` flag that calls `HHBench.open(get_tree())` and returns before the fight is built. Until then: `godot --path . --script res://src/arena/tools/bench_run.gd`.
- **R4** `src/game/arena_view.gd` / `fight.gd` (your call how): on a "pad" hex, place the unit at `max(hex_height, 0)` (water level) instead of the bed, and on "water" at the bed (wading). `HHArena.world(h)` returns the bed for both today; `asset.meta.water_level` is 0.
- **R5** `src/game/arena_view.gd`: when the arena id is "pond", draw `HHPondGen.build_both(gen.params).asset.instantiate()` instead of the grass heightfield, and use `asset.lights` through `HHArenaStage.sun/sky` (both in `src/arena/stage.gd`). The `gen` block in `arenas/pond.json` carries the params.
