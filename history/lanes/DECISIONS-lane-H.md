## Requests to the integrator / other lanes

- R-H1 (boot.gd): add `--hunt [--seed N] [--weapon id]` -> `HHHunt.start(shell, { "seed": seed, "weapon": weapon })`, with `shell` = the HHShell instance (or `HHHuntShellStub.new()` added to the boot node until it lands). `run.bat --hunt` then plays the loop.

HHHunt duck-types both and falls back to `HHHuntShellStub.launch_fight` when `play` is missing. Please confirm the lobby's class name: HHHunt looks for `HHLobby`, then `HHLobbyScreen`, then `res://src/game/lobby/lobby.gd`.
- R-H3 (lobby, Lane L): when `cfg.locked` contains `arena` / `monster`, grey those tiles out; emit `finished({ result: "play", cfg })` and `finished({ result: "back" })`.
- R-H4 (core, optional): make `HHCameraRig.DIST_MAX` a `var dist_max` (default 40) so the world map can drop the scaled parent of H502.
- R-H5 (fight): the `finished` payload should carry `max_hp` and `monster_max_hp` (HHHuntFightWatch already does); HHResults falls back to HHTune when they are missing.
