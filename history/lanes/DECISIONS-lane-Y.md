| H80 | 2026-10-20 | The hunter is rebuilt after the author's reference (`design/art/hunter_ref/reference.jpg`, a comic cover; under `design/`, which the export filter already leaves out): an 8-head heroic female figure, smooth and continuous. `tools/blender/build_base_rig.py` v2 lofts the torso and both legs as ONE welded mesh (each leg's top ring is half the torso's crotch ring plus a shared crotch seam), with superellipse cross-sections, bust and glute bumps, and full-at-the-top thighs that taper hard to a slim knee; arms and head are lofts tucked into it; every vertex carries a smooth normal averaged over its welded part, written as custom split normals, so the per-role mesh split (H303) leaves no seam. | H84 | 2026-10-20 | Comic ink outline, default ON, `HHTune` `ink_on` (F1; 0 = off), `ink_px` 2.4 (line width in pixels on a 1080-line screen), `ink_max_m` 0.05 (cap). Inverted hull: `HHInk` (`src/game/fx/ink_outline.gd`) adds an `ink_<mesh>` sibling per body mesh: all surfaces merged, normals averaged per welded position (no cracks at hard edges or role seams), same Skin and skeleton so it deforms with the body; `shaders/ink_outline.gdshader` (unshaded, cull_front) pushes back faces out by a constant fraction of the SCREEN height, so the line is the same weight at the gameplay camera and never fattens up close. The pixel size is measured by projecting a 1 m step (VIEWPORT_SIZE reads 0 in vertex() and PROJECTION_MATRIX[1][1] was not the cotangent here: both tried, both gave a zero-width line). Compatibility-safe (no instance uniforms, no screen reads). No static resource caches (the hull mesh is cached as meta on its source mesh), so no "resources still in use" at exit. | Author ("Especially agree with the comic ink outline" -> wanted, default on), build Claude | | current |
