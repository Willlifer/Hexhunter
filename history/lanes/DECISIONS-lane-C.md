## Requests

- **R-C1 (Lane S, `src/core/sim.gd`): revive progress as an event, every tick while it fills.** Exact shape the fight and HUD read (any one of `frac` / `ticks`+`total` works; `frac` preferred):
  `_emit({ "type": "revive", "id": downed_id, "by": reviver_id, "ticks": progress_ticks, "total": int(HHTune.value("revive_ticks")), "frac": float(progress_ticks) / HHTune.value("revive_ticks") })`
  and when it completes `_emit({ "type": "revived", "id": downed_id, "by": reviver_id })`. Keep `u.downed: bool` on the unit (R-N4 so it replicates). A hunter going down needs no event (the fight watches the field), but a `death` event for a downed hunter is fine (the body already holds the kneel). Please also keep `alive(u)` false while downed and `hp` at 0, and make `add_player` fan out from `arena.spawns.player[0]` (Lane C's stand-in moves a hunter only when it lands on another hunter's hex, so it goes quiet by itself).
- **R-C2 (Lane S, tune):** name the revive length `revive_ticks` in `HHTune.DEFAULTS` (the fight's fallback reads that key when an event carries no `total`).
- **R-C3 (integrator, guide/02):** fold Lane C's names: `HHParty`, `HHLobbyCoop`, `HHCoopWire` (HHNet message kind 40: Lane N, please keep 40-49 free), `HHFight.payload()` keys `max_hp, monster_max_hp, local_id, net, hunters[{ id, peer, name, weapon, hp, max_hp, downed, downs }], host_left`, boot flags `--host --join --name --port --peers`.
- **R-C4 (integrator, export):** copy `launchers/Host.bat` and `launchers/Join.bat` into `dist/` with the others; Windows may ask to let Hexhunt through the firewall the first time someone hosts.
- **R-C5 (Lane N, optional):** `HHSession.start()` clears every member's ready flag without broadcasting; the lobby re-readies on return, so nothing breaks, but a STATE after the reset would keep clients' ticks honest.
